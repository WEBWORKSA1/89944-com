How AI products are billed

Most large-language-model APIs charge per token, with separate rates for input (your prompt, context and documents) and output (the model's reply). Output tokens usually cost several times more than input tokens. Many providers also discount cached or repeated input and offer cheaper batch processing.

Cost per request = (input tokens × input rate + output tokens × output rate) ÷ 1,000,000

Price on value, floor on cost

Your AI cost per user sets the floor; customer value sets the ceiling. Software buyers expect SaaS-like gross margins, so many AI startups target 60–80% after model costs. If the tool shows you can't hit that at a price customers accept, you have four levers: smaller models for easy tasks, aggressive caching, shorter outputs, or usage-based pricing above a fair-use cap.

Pricing models that work for AI

  • Seat + fair-use cap — predictable for buyers; protects you from power users.
  • Credits — prepaid usage that maps to your token cost.
  • Outcome-based — charge per resolved ticket, document or lead; captures value directly.

FAQ

How many tokens is a word?

In English, a common rule of thumb is roughly 0.75 words per token (about 4 characters). Code and other languages vary.

Why are my real costs higher than the estimate?

Hidden tokens: system prompts, chat history re-sent every turn, retrieved documents and retries. Measure real token counts from your logs and plug them in.
